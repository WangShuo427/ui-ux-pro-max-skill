## 2. Information Architecture

```
Firmware Security Cockpit
│
├── Upload & Pipeline          — firmware ingestion + multi-stage analysis
├── Overview Dashboard         — risk summary, KPI cards, pipeline status
├── Firmware Map               — binary layout + component tree + entropy heat map
├── Risk Center                — all findings ranked by severity; filterable table
```

## 12. UX / Accessibility Checklist

Based on UX rules `#100–#105` in `ux-guidelines.csv`.

### 12.1 Firmware Security–Specific Rules

- [ ] **Multi-stage progress** — Every analysis pipeline shows per-stage status + elapsed time + expandable log on failure (rule #100)
- [ ] **Risk badge dual encoding** — Risk level uses color + icon + text label everywhere; never color alone (rule #101)
- [ ] **AI content disclosure** — Every AI-generated section carries a visible "AI-generated · For reference only" banner (rule #102)
- [ ] **Error recovery path** — Analysis errors show cause + retry / skip / docs CTA; no silent failures (rule #103)
- [ ] **Destructive confirmation** — "Clear Memory Palace", "Delete history" require two-step confirmation with scope explanation (rule #104)
- [ ] **Dark mode text contrast** — Validate all text/background pairs; primary text must be ≥4.5:1 contrast in dark mode (rule #105)

### 12.2 General Accessibility (from UX Pro Max core rules)

- [ ] All icon-only controls have `aria-label` (ux rule: `aria-labels`)
- [ ] Tab order matches visual reading order (ux rule: `keyboard-nav`)
- [ ] Data tables have `aria-sort` on sortable columns (chart rule: `sortable-table`)
- [ ] Charts provide text summary for screen readers (chart rule: `screen-reader-summary`)
- [ ] Risk level communicated via text, not color alone (ux rule: `color-not-only`)
- [ ] Animations respect `prefers-reduced-motion` (ux rule: `reduced-motion`)
- [ ] All form inputs have visible labels (ux rule: `form-labels`)
- [ ] Error messages include cause + fix path (ux rule: `error-recovery`)

### 12.3 Interaction Quality

- [ ] File upload drop zone shows drag-over state
- [ ] Long-running operations disable the trigger button and show progress
- [ ] Toast notifications auto-dismiss in 4s; accessible via `aria-live="polite"`
- [ ] Back navigation preserves table filters, scroll position, active tab
- [ ] Clicking a Risk Center row navigates to Component Inspector with correct component pre-loaded
